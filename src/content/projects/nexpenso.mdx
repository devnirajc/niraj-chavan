Nexpenso turns bank statements into a picture of where the money goes. Upload a statement — CSV, Excel or plain text — and it categorises every transaction, flags duplicates by their reference number, and rolls everything up into dashboards: spending by category, balances per bank, upcoming bills and subscriptions, savings goals and investments.

## Under the hood

Nexpenso is a React app with Redux for state and React Router for navigation, built with Vite. Vendor code is split into separate chunks — React, Redux, charting and data handling — which the page preloads in parallel, so changing application code does not invalidate the cached libraries.
