K7 Computing is an Indian cybersecurity company that makes antivirus and threat-protection software for businesses and homes. As a Senior UI Engineer at Xpanxion, now UST Global, I built the front end of two parts of its consumer products: the **consumer console**, the account area where thousands of home users manage their licences and devices, and the **antivirus dashboard**, the screen that tells a user how well protected they are. This was client work, so there is no public repository.

- **Client:** K7 Computing, cybersecurity
- **Product:** the consumer console and the antivirus dashboard
- **Users:** K7's home customers, thousands of them, most of whom are not technical
- **My role:** Senior UI Engineer at Xpanxion. I built the front end of both, in Angular, TypeScript and RxJS, and worked with K7's back-end team on the APIs behind them
- **When:** between 2017 and 2019, during my time at Xpanxion (now UST Global)

## The business problem

These screens do two jobs for people who mostly aren't technical:

- **Tell them, at a glance, whether they are protected**, and what to do if they aren't.
- **Let them manage what they paid for**: see their plan and expiry date, renew or upgrade, activate a licence key on a new device, and manage the devices a multi-device licence covers.

## Architecture and design

The front end is Angular and TypeScript, with RxJS handling the asynchronous data from the REST APIs I worked on with K7's back-end team. Styles are in SCSS, with responsive layouts so the same interface works in desktop and mobile browsers.

The two products share one approach to data: every screen that depends on an API call has explicit loading, empty and error states, so a slow or failing back end never leaves a user looking at a broken screen.

## Key technical challenges

### Security status anyone can read

**Challenge.** The dashboard has a lot to report: the last scan and its results, threats found, items in quarantine, whether virus definitions are current, and alerts. Most users are not technical.

**Solution.** The dashboard leads with one overall state, protected or action needed, and keeps the details a click away.

### One interface for every screen size

**Challenge.** Both products have to work in desktop and mobile browsers.

**Solution.** Responsive layouts, so the console and the dashboard work the same in desktop and mobile browsers.

### No broken screens when the back end is slow

**Challenge.** Both products depend on API calls that can be slow, empty or fail.

**Solution.** Every API call has loading, empty and error states, so users always see something meaningful.

## Outcome summary

- **Key achievements:** the front end of K7's consumer console and antivirus dashboard, used by thousands of home users.
- **Design principle:** one clear answer to "am I protected?", with the details a click away.
- **Reliability:** loading, empty and error states on every API-backed screen, and responsive layouts across desktop and mobile browsers.
