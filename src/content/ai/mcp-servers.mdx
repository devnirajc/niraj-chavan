steps:
  - title: audit_page
    detail: >-
      Loads a URL in Chrome through Playwright, in light and dark themes at
      desktop and phone widths, opens every disclosure, runs axe-core with the
      WCAG 2.2 AA rules, and returns the violations grouped by rule, with the
      selectors involved.
  - title: check_contrast
    detail: >-
      Takes a foreground and background colour and says whether the pair meets
      WCAG for body text, large text or interface parts, with the ratio.
  - title: check_tokens
    detail: >-
      Reads a design-token file and checks every text and background pair in
      both themes, so a palette change can't quietly break contrast.
  - title: Read-only by design
    detail: >-
      No tool changes a file. The agent reports what failed and proposes a fix,
      and I review the fix like any other change.
